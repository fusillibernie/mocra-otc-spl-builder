# Official sources

Download these into this folder (and record the version and date) before writing SPL code.
Every code value in `src/` must trace back to one of them.

- [ ] SPL Implementation Guide: Cosmetic Facility Registration and Product Listing (FDA, latest version)
- [ ] SPL Implementation Guide with Validation Procedures (drug establishment registration and listing)
- [ ] FDA SPL validation rules / terminology files (cosmetic product categories, UNII, marketing categories)
- [ ] ESG NextGen API Guide (v1.2.1, August 2026, or newer)
- [ ] OTC Monograph order(s) for each monograph our OTC products rely on (OTC Monographs@FDA)
